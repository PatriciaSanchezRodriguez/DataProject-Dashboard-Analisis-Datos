# 📊 Nombre del Proyecto: Dashboard & Análisis de Datos :Ventas Amazon

 Este proyecto analiza las ventas de Amazón en distintas regiones 

## 🎯 Objetivos del Proyecto
**Transformación y limpieza de los datos.
**Análisis descriptivo de los datos.
**Dashboard.
**Informe explicativo del análisis.
**Readme del proyecto.

## 🛠️ Herramientas y Tecnologías
* **Excel**
  **Docx**


## 📁 Estructura del Repositorio
* `/data`: Contiene el dataset "cleaned_dataset" ; contiene el fichero Ventas Amazon.xlxs
* `/notebooks`: documento Control de pedidos de Amazón : contiene el análisis descriptivo de los datos y el informe explicativo de los datos ;documento EDA de limpieza de datos 
* `/dashboard`: dashboard 
*

## 🚀 Cómo Ejecutar el Proyecto
1. Abre el archivo `Ventas Amazon.xlxs` en Excel .
2. Abre el docunento Control Pedidos Amazon.docx y revisa el análisis descriptivo e informe explicativo .El contenido de ambos informes se ha fusionado en este único documento.
